# Changelog

All notable changes to this project will be documented in this file.

## v1.0.0

### Initial release
- Passive subdomain enumeration
- Multi-source aggregation
- Output normalization
- Result deduplication

## [1.0.1] - 2026-07-25

### Changed
- Refactored `recon.sh` for improved readability and maintainability.
- Added Bash strict mode (`set -euo pipefail`).
- Improved input validation using a readonly target variable.
- Standardized script structure with section headers.
- Updated completion messages for better consistency.
